# 实验 1A 网络嗅探器开发文档

本目录说明如何从零实现一个带 GUI 的网络嗅探器。当前项目只有实验课件，下面的目录、接口和技术方案均为开发设计，不代表代码已经实现。

建议按顺序阅读：

1. [需求与架构](01-需求与架构.md)：明确课程要求、功能范围、模块划分和数据结构。
2. [分步开发指南](02-分步开发指南.md)：按阶段编写代码，每阶段都有操作步骤、产物和完成标准。
3. [测试与提交清单](03-测试与提交清单.md)：准备测试流量、验证正确性、录制视频和整理提交材料。

## 依据与方案

依据：项目根目录的《实验 1 讲解 2026.pdf》，重点为第 2–3、9、11、14–15、65 页。

- 课件要求：带 GUI；必须实现实际抓包；支持协议过滤；尽量完善协议分析。
- 课件加分项：TCP 流追踪、进程关联，以及良好的 Wireshark 二次开发。
- 本方案选择：Linux、C++17、Qt 6 Widgets、libpcap、CMake。课件未强制这些语言与 GUI 框架。
- 本方案扩展：PCAP 保存与读取、DNS 解析、统计和测试样例，以便调试及演示。

## 最短实施路线

环境与构建 → 命令行抓包 → 基础协议解析 → GUI → 捕获/显示过滤 → PCAP 读写 → HTTP 识别 → TCP 流追踪 → 测试与提交。

先把每一阶段做成可运行、可验证的版本，再进入下一阶段。eBPF、内核模块和高速抓包框架不作为初版前置条件。
